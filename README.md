## Features

**Soundboard**
- 400+ sounds across categories (memes · hype · comedy · drama · gaming · notifications …) with instant search and pack filters.
- On-demand cloud library for clips plus a local set that works fully offline.
- Favourites, named favourite groups, last 3 searches, and multiple sort modes.
- Export a recording or a clip to **WAV**.

**Voice FX**
- Record from the microphone and transform it with four filters: Chipmunk · Monster · Robot · Echo.
- All processing happens **on-device** — no audio is uploaded anywhere.

**Timer**
- Large-screen challenge timer, optional keep-screen-awake, and permission-gated alerts.

**StreamLock**
- Big buttons, no ads, screen kept awake, and an exit confirmation — designed for live streaming.

**Ads (Adsterra)**
- Banners + in-feed slots between grid rows + a 10-second launch ad + a 20-second rewarded ad.
- Every ad surface is labelled "Ad", and nothing opens without a user tap.
- **Offline:** no empty modals and no blocked features — the free alternative always works.

**StreamCue Pro (optional · time-limited)**
- Removes every ad and unlocks all sounds and filters for a limited period, activated by a code.
- Codes are 20 characters with an HMAC signature, generated by a developer-side tool and verified against a signed online registry.
- The Pro surface in the app is controlled by `proEnabled` in `www/app-config.js`.

## Quick start

```bash
git clone <repo> && cd streamcue-studio
npm install

python3 tools/serve_dev.py        # http://localhost:5173
```

## Build

```bash
python3 build.py -os android -env setup     # JDK 17 + Android SDK 34 (into ~/.cache/scs-tools)
python3 build.py -os android -env status    # verify the toolchain

python3 build.py -os android -build apk     # → release/StreamCue-Studio-1.0.0.apk
python3 build.py -os android -build aab     # store bundle
python3 build.py -os web     -build bundle  # offline web bundle
python3 build.py -os windows -build exe     # Windows (Electron)
```

> ⚠️ `release.keystore` is the app's signing key — losing it means you can never ship an update.
> Never commit it to a public repository, and move the passwords to environment variables before publishing.

- **No account, no sign-in, no personal data collected.** Your recordings and settings stay on your device.
- The microphone is requested **only** when you tap record, and the audio never leaves the device.
- Ads are served by **Adsterra** (an independent third party) — see the privacy policy for what it processes.
